# FdF

## Description
This project is about creating a simple wireframe model representation of a 3D land-
scape by linking various points (x, y, z) thanks to line segments (edges).
For this, you must use the MiniLibX(minilibx-linux.tgz) available in the project page.

### How it works ?
You take in input from .fdf files, available in the project page too, test_maps(maps.zip).
The subject already get you fdf_linux executable to compare with my program.
You can also create your own .fdf files, but be careful to respect the format.
Each line of the file represents a row of the map, and each number represents the
altitude (z) of a point in the map.
All the points have a distance of 1 between them on the x and y axis.
